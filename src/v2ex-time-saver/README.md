# v2ex-time-saver

逛 V2EX 省时间的脚本。

## 功能

一个 Tampermonkey 脚本，给 V2EX 加了用户标签、评论高亮、讨论嵌入和多页合并。

## 为什么做

V2EX 热门帖子回复一多就很难看。好观点被淹没，恶意用户反复刷屏，翻页还打断阅读。这个脚本解决了这些问题：

- 给用户打标签，建立个人信誉系统
- 所有分页合并成一页，不用跳转
- 引用的讨论直接内嵌显示，减少跳转
- 根据标签分数给评论上色，一眼看出谁是谁

## 使用说明

### 用户标签

1. 每个作者名旁边有个标签按钮（🏷），楼主的也有
2. 点击打开标签面板，有快捷标签或自定义输入
3. 快捷标签："不说人话"（负评）和"智者"（好评）
4. 标签通过 `GM.setValue` 持久化，重启浏览器不会丢

### 帖子增强

- **多页合并**：抓取所有评论页合并到一起
- **讨论内嵌**：引用的 V2EX 讨论直接抓取内嵌显示
- **评论排序**：按点赞数排序，好内容排前面
- **折叠/展开**：给评论串加折叠按钮
- **自动签到**：检测并处理每日签到
- **锚点定位**：自动跳转到 URL hash 指定的评论

### 高亮颜色

- 绿色系：正分标签用户
- 红色系：负分标签用户
- 颜色深浅随分数变化（-3 到 +3）

## 支持站点

- `*.v2ex.com`

## 安装

把生成的 `dist/v2ex-time-saver.user.js` 文件装到 Tampermonkey 里就行。
