# hupu-time-saver

虎扑论坛搭子：给用户打标签，评论高亮显示。

## 功能

一个 Tampermonkey 脚本，给虎扑论坛（hupu.com）加了用户标签功能，根据标签累计分数给评论上色。

## 为什么做

虎扑帖子里水贴和有料的评论混在一起，没个标记机制的话得花大量时间筛无用内容。这个脚本帮你建个人信誉系统：

- 给用户打"串子"（水军）或"家人"（自己人）标签
- 一眼看出哪些评论是打过标签的用户发的
- 正分用户评论自动高亮

## 使用说明

1. 帖子评论区每个作者名旁边有个标签按钮（🏷）
2. 点击打开标签面板，有快捷标签或自定义输入
3. 快捷标签："串子"（水军）和"家人"（自己人）
4. 标签分数 -3 到 +3，影响评论高亮颜色
5. 标签通过 `GM.setValue` 持久化，重启浏览器不会丢
6. 多页帖子：会从所有页面加载作者信息，确保标签准确
7. 用 MutationObserver 处理动态加载的评论（无限滚动）

### 高亮颜色

- 绿色系：正分标签用户
- 红色系：负分标签用户
- 颜色深浅随分数变化（-3 到 +3）

## 安装

把生成的 `dist/hupu-time-saver.user.js` 文件装到 Tampermonkey 里就行。
