# article-preloader

小说网站自动预加载下一章，不用等。

## 功能

一个 Tampermonkey 脚本，读小说时自动预加载下一章。把多页章节合并成一页，切章不用等加载。

## 为什么做

很多中文小说网站把一章拆成好几页，翻页还得整页刷新，等半天还打断阅读节奏。这个脚本解决了这些问题：

- 把当前章节的所有分页合并成一页连续阅读
- 后台预加载下一章
- "下一章"按钮点了直接换内容，不用跳转

## 使用说明

1. 页面加载后自动合并当前章节的续页
2. 用 `GM_xmlhttpRequest` 预加载下一章并缓存 HTML
3. "下一章"按钮换成即时切换模式
4. 支持键盘导航：
   - `→` — 下一章（即时切换）
   - `←` — 上一章（正常跳转）
   - `Enter` — 返回章节列表
5. 预加载失败自动重试，最多 10 次
6. 到最后一页显示"今日文尽"

## 支持站点

- `www.xbiquge.so`
- `www.biduoxs.com`
- `www.sudugu.org`
- `www.tongrenxsw.com`

## 安装

把生成的 `dist/article-preloader.user.js` 文件装到 Tampermonkey 里就行。
