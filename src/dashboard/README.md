# dashboard

个人仪表盘浮层，双击 Shift 呼出。

## 功能

一个 Tampermonkey 脚本，在支持的站点上提供可定制的仪表盘浮层。聚合了多个数据源——V2EX 热帖、天气空气质量、小说更新、Reddit 首页、TNews 科技新闻——一个面板全看。

## 为什么做

刷 V2EX、Reddit、看天气、追小说更新，得来回切标签页手动刷新，挺烦的。这脚本把这些信息都收到一个浮层里，后台自动刷新，统一界面管理。

## 使用说明

1. 双击 `Shift`（可配置）打开/关闭仪表盘
2. 也可以从 Tampermonkey 菜单打开："打开仪表盘" / "编辑仪表盘配置"
3. 每个数据源独立抓取，有各自的缓存策略
4. 后台会自动刷新过期的数据
5. 通过 JSON 配置（Tampermonkey 菜单 → "编辑仪表盘配置"）
6. 支持域名白名单，限制快捷键生效范围

### 数据源

| 数据源 | 说明                                     |
| ------ | ---------------------------------------- |
| V2EX   | v2ex.com 热帖                            |
| 天气   | Open-Meteo / CMA 的实时天气和空气质量    |
| 小说   | 追更小说的章节更新状态                   |
| Reddit | reddit.com 首页帖子                      |
| TNews  | 通过 RSSHub 抓取的科技新闻（带镜像回退） |

### 快捷键

- `Shift`（双击）— 打开/关闭仪表盘
- `Escape` — 关闭仪表盘

## 支持站点

- `mail.google.com`
- `v2ex.com` / `*.v2ex.com`
- `github.com`

## 安装

把生成的 `dist/dashboard.user.js` 文件装到 Tampermonkey 里就行。
